# Segurança e privacidade

Esta publicação foi preparada a partir de uma cópia dos arquivos de pesquisa. Os originais não foram movidos nem apagados.

Não fazem parte do repositório:

- endereços Bluetooth reais;
- coordenadas e configurações locais reais;
- caminhos de usuário do Windows;
- logs de execução e CSV de bateria;
- capturas HCI, PCAP e arquivos compactados;
- caches Python e backups de trabalho;
- arquivos de sessão, tokens, cookies ou credenciais.

Antes de anexar novos diagnósticos, revise endereços MAC, nomes de dispositivos, números de série, coordenadas e outros identificadores.
